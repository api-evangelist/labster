# Labster

> Labster is a virtual laboratory simulation platform for universities and high schools, delivering 300+ immersive 3D science simulations across Biology, Chemistry, Physics and Health Sciences. Students run experiments in a browser with automated grading and unlimited practice attempts. Labster is delivered to institutions through their LMS as a 1EdTech LTI 1.3 tool, not through a public developer API.

## Important note for agents

Labster publishes **no public REST API, no OpenAPI description, no developer portal and no API keys**. Do not attempt to construct calls against `api.labster.com` or `developer.labster.com` — neither host resolves. Integration with Labster is an administrative LTI 1.3 tool registration performed inside the institution's LMS, using a tool configuration URL and client ID issued per customer by a Labster Customer Success Manager.
